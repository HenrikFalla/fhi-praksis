# Guide: Publisering til GitHub Pages med GitHub Actions

Dette prosjektet inneholder en interaktiv leksjon og steg-for-steg-guide (i `index.html`) som viser hvordan du setter opp automatisk publisering til **GitHub Pages** ved hjelp av **GitHub Actions** for ditt eget HTML/CSS/JS-prosjekt.

## Kjøre guiden lokalt

1. Installer avhengigheter:
   ```bash
   npm install
   ```
2. Start utviklingsserveren:
   ```bash
   npm run dev
   ```
3. Åpne adressen som vises i terminalen (vanligvis `http://localhost:5173`) i nettleseren for å følge guiden.
